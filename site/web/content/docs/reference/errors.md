This page will list each error you can hit while declaring claims (an id issued twice, a move
without `does`, a flow whose witness isn't live, a retired id coming back), each with a stable
code, an example, and the fix. Today the errors are plain messages without
codes; the [claims page](/docs/reference/claims/#what-the-build-checks) lists them. Giving each
error a stable code, and this page with them, is
[issue #99](https://github.com/iamnbutler/cairn/issues/99).
