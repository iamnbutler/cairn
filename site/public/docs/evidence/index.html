Evidence

The example apps' maps

Every claim each example makes, with its evidence and screenshots, generated from the build.

Each map is built from an app's claims and whatever evidence the build had: the axiom audit, fuzzing, conformance runs against the running app, and screenshots from the app's own frames. Nothing on a map is written by hand. The evidence ladder explains what each kind of evidence means.

MapWhat it covers
Counter^1–^7: two moves, two flows, an assumption and a retired claim
Basics^101–^109: a field, a keyed list and an invariant
TodoMVC^201–^224: the full TodoMVC spec
The trusted basethe host's assumptions, each with the fuzz check that gathers its evidence

The maps are snapshots: they show the evidence from the last time they were built, which is printed on each. Clock, Tray and Yap don't have published maps yet.

Cairn is research, and these docs grow with it. The code samples are included from the source that make check builds.
