The cairn tool

The command line for building, checking and shipping a Cairn app. Planned; today the repository's make targets do its work.

Not built yet

There is no cairn command today. It is planned in issue #75, together with making Cairn a package an app can depend on. This page says what it will do and how to do each thing now.

Planned commands

CommandWhat it will doToday
cairn newstart an app in its own repositoryadd an app beside the examples (how)
cairn buildbuild the Lean app and its Swift hostmake build
cairn runopen the app in a windowmake demo DEMO=Cairn<App>
cairn checkeverything a change must passmake check
cairn mapbuild the app's mapmake map APP=<App>
cairn fuzzclaim-driven fuzzingmake fuzz APP=<App>
cairn conformreplay the model against the running appmake conformance APP=<App>
cairn bundle --signa signed .appmake bundle APP=<App> SIGN=<identity>
cairn benchthe app's benchmarksmake bench (Cairn's own)
cairn docdocs from the code (#74)none
cairn doctorcheck the toolchainnone
