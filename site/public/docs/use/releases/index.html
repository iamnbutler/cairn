Release notes and compatibility

What changed in each version of Cairn, and what an app can rely on across versions.

Cairn has no releases yet: apps live in its repository and build against whatever is on its main branch. This page will hold the notes for each version and say what stays compatible: the Lean API, the host protocol's versions, and Cairn's own claims, which will be published as a versioned contract with their ids. Versioning starts when an app can depend on Cairn at a pinned version, issue #75.

Cairn is research, and these docs grow with it. The code samples are included from the source that make check builds.
