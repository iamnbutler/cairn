API reference

Every module, type and declaration in Cairn, and every claim it makes, generated from the code.

The API reference will be generated, never written by hand: cairn doc run on Cairn itself, the way rustdoc documents a Rust crate. It will have a page per module, type and declaration, with signatures and doc comments, and a page per claim with its statement, its proof and the evidence from the build, addressed by its ^N id. cairn doc is issue #74, and it publishes to /docs/api/, which doesn't exist until it lands.

Until then, the claims reference covers the claim commands, and the Book's chapters include the definitions they use (Node, Style, App, Effect, Request, Sub) straight from the source.

Cairn is research, and these docs grow with it. The code samples are included from the source that make check builds.
