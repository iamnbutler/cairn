Cairn by Example

Four apps from the repository, read through their source, from two buttons to an app used every day.

Each example is a real app in lean/Examples/ with a Swift executable in host/Sources/. The samples on these pages are included from that source.

ExampleWhat it showsRun it
Countertwo moves, two flows, presence and pressability proved in every statemake demo DEMO=CairnCounter
Basicsa text field, a list with keyed controls, wrapped text, an invariantmake demo DEMO=CairnBasics
TodoMVCthe full TodoMVC spec: editing in place, filters, double clicks, focusmake demo
Yapporting a real menu bar app one to one: effects, surfaces, a parity auditmake yap

Two more apps in the repository aren't written up yet: Clock, a stopwatch that is the example for effects (the Book's effects chapter uses it), and Tray, a menu bar item with an overlay panel, the example for surfaces.

Counter, Basics and TodoMVC each have a published map: every claim, its evidence, and screenshots.

Cairn is research, and these docs grow with it. The code samples are included from the source that make check builds.
