Cairn by Example

Basics

A text field, an Add button, a list of items you can check off or delete, and a count of what's left.

Basics is the first app with text input and a list. It shows keyed controls (one checkbox per item), a field whose editing comes from the framework, wrapped text, and an invariant proved over every reachable state.

IdKindWhat
^101movethe New item field: edits, and Enter adds
^102moveAdd
^103move, keyedan item's checkbox, ^103#k for item k
^104move, keyedan item's delete button, ^104#k
^105invariantthe count of items left is right, and item ids are distinct
^106placethe window
^107–^109flowadd and finish; blank text adds nothing; add, then delete

Its map: /map/basics/. Run it with make demo DEMO=CairnBasics.

State

The state keeps a running count of items left rather than recomputing it in the view. The invariant ^105 is what makes that safe.

Adding an item

The field's move answers edits and Enter; Add's answers a press. Both use the same add, and the same post.
