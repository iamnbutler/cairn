Cairn by Example

Yap

Porting a real dictation app to Cairn one to one, with its original as the spec.

Yap is a small dictation app for the Mac that its author uses every day: hold a key, talk, and the transcript is typed into the app in front. It is about 1,500 lines of Swift, and almost all of it lives outside its window: a global key, the microphone, timers, a network request, files, sounds, and typing into another app. Its UI is a menu bar menu and an overlay that never takes focus.

Yap (Cairn) is the same app rebuilt on Cairn. Its state, its decisions and its menus are Lean; the Swift host captures audio, hears the key, makes the request, writes files and types the text, each an effect Lean asked for. It reads and writes the original's files, so a person can switch between the two.

This is the example to read for porting an existing app. It isn't a tutorial: the app is large (its Lean is in lean/Examples/Yap/), and these sections show the decisions that matter.

The original is the spec

A port can drift from what it replaces in a hundred small ways: a message worded differently, a string counted in Unicode scalars instead of characters, a file created with the wrong permissions. So the port keeps a parity table: one row per behaviour of the original, with the original's source line, what the port does, and a status.

  • same: the port already did what the original does.
  • fixed: it didn't, and now does, with a test.
  • bug fix: the port deliberately differs, because the original is wrong. Each has an issue on the original's tracker.
  • open: a difference that needs a decision.

Where the original leans on a system library for text (how Swift counts characters, how NSRegularExpression folds case), the port was compared against that library directly, on generated inputs, rather than against its documentation: for example 120,766 strings against Swift's own character counting, with no mismatches.

What's not covered yet

  • Yap's map isn't published.
  • The parity table's open rows need decisions, chiefly whether the port should replace the original outright rather than sit beside it.
  • Apps can't yet declare host effects of their own: the effects Yap needed were added to Cairn itself. Whether that changes is part of issue #75, which also moves Yap into its own repository.
