Cairn.Fuzz.Trusted.Gen

lean/Cairn/Fuzz/Trusted/Gen.lean

Generators for the trusted-base fuzzer

Random frames for differential fuzzing of the Swift frame decoder (docs/fuzz.md, "Trusted base"). Built on workstream L's SplitMix64 (Cairn.Fuzz.Gen), so a seed replays exactly.

Every generated frame fits the wire (fitsFrame): integers are drawn inside i32/u32, with a bias toward the edges (0, ±1, the extremes), because that is where a hand-written decoder slips. Strings lean on what breaks text code: astral scalars (surrogate pairs in UTF-16), the last scalar before and after the surrogate block, U+10FFFF, NUL, combining marks, ZWJ sequences, skin tones, flags, CJK, right-to-left scripts, line breaks and the BOM.

Imports Cairn.Fuzz.Rng, Cairn.Frame.Encode, Cairn.Frame.Events
