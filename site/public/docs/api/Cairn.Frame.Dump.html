Cairn.Frame.Dump

lean/Cairn/Frame/Dump.lean

A canonical text dump of frames and events (docs/frame.md, "Canonical dump"). The Swift decoder's tests print the same format and compare it line for line with Lean's, and it is a readable form for the debug socket. Strings print printable ASCII as itself and every other Unicode scalar, " and \ as \u{HEX}.
