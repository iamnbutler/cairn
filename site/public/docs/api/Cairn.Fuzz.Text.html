Cairn.Fuzz.Text

lean/Cairn/Fuzz/Text.lean

The default text generator

Scripts of TextOps for a field's edit moves. Each operation in a script is sent as its own event, the way a person's typing arrives. The pool leans on what breaks text code: blanks, emoji with skin tones and ZWJ sequences, flags, combining marks, CJK, long strings, and IME compositions (setMarked one to three times, then a committing insert or an unmark).
