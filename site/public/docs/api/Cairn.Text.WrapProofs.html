Theorems about line breaking (Cairn.Text.Wrap)

For every text cs, width W and offsets o (any function: nothing here assumes the offsets are monotone, so it holds for every TextMetrics, valid or not):

  1. Lines fit. allLines_fit: every line is at most W wide, or is a single scalar (a scalar wider than the line, which no break could help).
  2. Lines tile the text. allLines_cover and allLines_tiles: the lines are nonempty ranges in order, and the text is g₀ ++ l₀ ++ g₁ ++ l₁ ++ … ++ lₖ ++ gₖ₊₁ with every gap gᵢ made of break spaces only (possibly empty, where an over-wide word was cut).
  3. Line count. lines_length_le: at most maxLines lines.
  4. Keep. lines_tail, lines_head: tail keeps exactly the last min n k of the k lines, head the first.

Cover (sp : Nat → Prop) (len : Nat) : Nat → List (Nat × Nat) → Prop

Cover sp len p rs: the ranges rs are nonempty and in order, the first starts at or after p, the last ends by len, and every index in [p, len) outside them satisfies sp.

Tiles : List Char → List (List Char) → Prop

Tiles cs ls: cs = g₀ ++ l₀ ++ g₁ ++ l₁ ++ … ++ lₖ ++ gₖ₊₁ where ls = [l₀, …, lₖ], every line is nonempty and every gap is break spaces.

    l ≠ [] → Tiles rest ls → Tiles (g ++ l ++ rest) (l :: ls)

wordsFrom_cover (cs rest : List Char) (i : Nat) :
  i + rest.length = cs.length →
    (∀ (k : Nat), rest[k]? = cs[i + k]?) →
      ∀ (cur : Option Nat) (p : Nat),
        (match cur with
          | none => p ≤ i ∧ ∀ (k : Nat), p ≤ k → k < i → cs[k]? = some ' '
          | some a => p ≤ a ∧ a < i ∧ ∀ (k : Nat), p ≤ k → k < a → cs[k]? = some ' ') →
          Cover (fun k => cs[k]? = some ' ') cs.length p (wordsFrom rest i cur)

Words cover the text: what lies between and around them is break spaces.
