Cairn.Claims.Registry

lean/Cairn/Claims/Registry.lean

The claim registry: an environment extension holding one entry per claim declared by the claim commands, in this module and every module it imports. The commands consult it for the compile-time checks; lake exe ledger and lake exe claims read it from the imported environment.

Compile time only (imports Lean); see Cairn.Claims for why that matters.

Imports Lean, Cairn.Claim

Cairn.Claims.cairn.claims.scope

lean/Cairn/Claims/Registry.lean:24
scope : Lean.Option String

The package whose claims a module declares: ^301 in a module built with scope yap is the claim yap^301. Ids are unique within a scope, never across scopes, so a package's ids are its own and the ids of the packages it depends on can't collide with them. Set once per package, in its lakefile: leanOptions := #[⟨weak.cairn.claims.scope, "yap"⟩] (weak., because Lake passes it to every module, including those that don't import the claim commands). Cairn's own modules use the default, cairn`.
