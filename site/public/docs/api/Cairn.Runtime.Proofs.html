  (∀ (p : ClaimId) (a : Action),
      a ∈ (route m s (Event.menuOpen p)).snd →
        ∃ it, Shown.statusOf p s.surfaces = some it ∧ a = Action.press it.control) ∧
    (∀ (p : ClaimId) (r : ControlRef) (a : Action),
        a ∈ (route m s (Event.menuSelect p r)).snd →

Menu actions name menu items. Opening a status item's menu presses only its control; a selection presses only an enabled item of the menu the runtime holds for it now; closing presses nothing.
