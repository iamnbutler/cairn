Cairn.Frame.Menu

lean/Cairn/Frame/Menu.lean

Frame.ofMenu: a status item's menu description becomes the flat list of menu records the frame carries (docs/frame.md, "Menu records"), parents before children, as the accessibility list is.

Theorems: controls_ofMenu (the records' controls are exactly the description's actionable items, in order: what the host's NSMenu is built from is what the presence and enablement proofs are about), enabled_ofMenu (likewise for the enabled ones) and parent_lt_ofMenu (every parent index points at an earlier record, and at a submenu).
