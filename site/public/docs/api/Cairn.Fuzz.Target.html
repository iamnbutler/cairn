Cairn.Fuzz.Target

lean/Cairn/Fuzz/Target.lean

What the fuzzer knows about an app

A Target bundles a machine (and the App built from it, if any) with what the claims say about it. fuzz_targets% (Cairn.Fuzz.Collect) builds one per machine in the Examples modules at compile time, so an app needs no fuzz code of its own.
