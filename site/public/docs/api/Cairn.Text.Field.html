Cairn.Text.Field

lean/Cairn/Text/Field.lean

Single-line text editing

Field is the editing model behind every text field: the text, caret, anchor, IME marked range, undo and redo stacks, and placeholder. Field.apply gives the meaning of every TextOp; Field.view turns a field into the FieldView the view layer draws.

The text is a List Char, so every index is a Unicode scalar position, the same unit as String.length and TextMetrics.offsets. Lists are used rather than String because every edit is a splice (take a ++ s ++ drop b), and core Lean's List lemmas about take, drop and length make the proofs short; String's byte-indexed API would put a UTF-8 decoding step between every theorem and its statement. The view converts with String.ofList (String.length_ofList keeps the indices meaning the same thing).

The behaviour is specified, op by op and against macOS's NSTextView, in docs/text.md. Theorems are in Cairn.Text.Proofs.

Cairn.Text.isWordChar

lean/Cairn/Text/Field.lean:47
isWordChar (c : Char) : Bool

A word is a maximal run of word characters: ASCII letters, digits and _, and every non-ASCII scalar except the Unicode spaces below. Everything else (ASCII punctuation and spaces) separates words. This is deliberately simpler than NSTextView, which uses ICU word boundaries and a dictionary for scripts without spaces; see docs/text.md.

Cairn.Text.Field.setMarked

lean/Cairn/Text/Field.lean:183
setMarked (f : Field) (s : String) (selStart selLen : Nat)
  (replace : Option (Nat × Nat) := none) : Field

IME composition: replace the marked text (or, when composition starts, the selection) with s, mark it, and put the selection at [selStart, selStart + selLen) within it, clamped. Starting a composition opens an undo step; the whole composition, through its commit, is that one step. An empty composition ends it. replace is as for insert.
