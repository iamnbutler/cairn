Cairn.Effects

lean/Cairn/Effects.lean

The outside world as data (docs/effects.md): the time the host reports, the requests an app can make and the replies they get, and the subscriptions an app can ask for. Cairn.Input builds Effect and Event on these; the runtime's handling is Cairn.Runtime.World.

Something the host does that answers back. Closed: adding a kind is a constructor, its encoding, a Reply.answers case and one host handler (docs/effects.md).

Append to the file, creating it (mode 600) and missing parent directories.

listDir (path : String) : Request

The names in a directory (not . and ..), sorted by their UTF-8 bytes.

deleteFile (path : String) : Request

Remove a file or a symbolic link; never a directory.

frontmostApp : Request

The app in front: its process id and name.

Whether the app holds p; with prompt, the system also asks the person if it doesn't.

Bring process pid to the front and type text into it as key events, then Return if pressReturn. Needs Accessibility.

upload (method url : String) (headers : List (String × String))
  (secret : Option Secret) (body : List Part) (timeoutMs : Nat) : Request

http with a body of parts the host assembles and an optional secret header (OpenAI's transcription request: multipart framing from Lean, the clip's WAV and the key from the host).

forgetClip (clip : Nat) : Request

The host may drop the clip's samples.

openItem (target : String) : Request

Open target with its default app (the Finder for a folder, the default editor for a text file, System Settings for its URLs): a path (~/ is the home folder) or a URL with a scheme.

appRunning (bundleId : String) : Request

Whether an app with this bundle identifier is running.

readDefault (domain key : String) : Request

The value of key in the defaults domain domain (defaults read domain key), as UTF-8 text: a string as it is, a number or a boolean as its text (booleans as 1 or 0).

makeDir (path : String) : Request

Create the directory and its missing parents, each private (mode 700); done if it is already a directory.

Cairn.Sub

lean/Cairn/Effects.lean:152
Sub : Type

An outside input an app asks for, as data derived from its state.

Constructors
every (ms : Nat) : Sub

A tick every ms milliseconds (at least 1), from the host.

watchFile (path : String) : Sub

changed whenever the file at path changes: written, replaced, created or removed.

record (clip : Nat) : Sub

Record clip from the microphone while active: started once the microphone is running, then audio; or failed if it can't start. Stopping it stops the microphone. The host keeps the samples for Part.wav. Needs Microphone.

globalKey (code : Nat) (modifier : Option Nat) : Sub

The key with virtual key code code (with modifier, the NSEvent.ModifierFlags bit that tells a modifier key's press from its release): keyDown, keyUp, and otherKey for any other key pressed while it is down. Needs Accessibility.

Cairn.SubEvent

lean/Cairn/Effects.lean:177
SubEvent : Type

What an active subscription reports.

Constructors
tick : SubEvent

every's tick.

changed : SubEvent

watchFile's file changed.

audio (frames peak : Nat) (windows : List Level) : SubEvent

record: frames more samples, their largest absolute value peak, and the 20 ms windows they complete, in order from the start of the clip.

started (t : Nat) : SubEvent

record: the microphone is running, since monotonic milliseconds t (when its start returned). Sent once, before any audio, and never after a failed that says it could not start.

keyDown (t : Nat) : SubEvent

globalKey: the key went down or up, or another key went down while it was held, at monotonic milliseconds t (the clock of Time.mono).

keyUp (t : Nat) : SubEvent
otherKey (t : Nat) : SubEvent
failed (fault : Fault) (message : String) : SubEvent

The subscription could not run (a permission missing, no microphone). It may still be running; an app stops it by not asking for it.
