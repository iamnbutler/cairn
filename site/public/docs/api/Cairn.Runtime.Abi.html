Cairn.Runtime.Abi

lean/Cairn/Runtime/Abi.lean

The Lean side of the app ABI. The host (workstream G) loads one app per binary and calls three exported functions; each app file defines them by applying these generic functions to its App, a Config and a Boundary:

@[export cairn_app_init]
def appInit (w h scalePercent : UInt32) : Runtime.State MyApp.State :=
  Runtime.initState MyApp.app cfg w h scalePercent
@[export cairn_app_step]
def appStep (s : Runtime.State MyApp.State) (events : ByteArray) : Runtime.State MyApp.State :=
  Runtime.stepBytes MyApp.app cfg boundary s events
@[export cairn_app_frame]
def appFrame (s : Runtime.State MyApp.State) : ByteArray := Runtime.frameBytes boundary s

Lean 4.35 rejects @& on @[export], so every argument is owned: the host passes its reference to the state into cairn_app_step and keeps the one that comes back, and calls lean_inc on the state before cairn_app_frame if it keeps using it. See docs/runtime.md.
