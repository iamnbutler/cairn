Cairn.Frame.Encode

lean/Cairn/Frame/Encode.lean

Frame byte format v1 (docs/frame.md): specification encoder Wire.Enc.frame, decoder Wire.Dec.frame, the executable encoder encodeFrame (proved equal to the specification and installed with @[csimp]), and the round trip decodeFrame_encodeFrame.

Layout, all little-endian:

header     "CAFR" u16 version=1 u16 flags=0 i32 w i32 h                       16 bytes
draws      u32 count u32 byteLength, then count records
ax         u32 count u32 byteLength, then count records
textInput  4 bytes [present, hasMarked, 0, 0], then the rest of the record when present
cursor     4 bytes [cursor, 0, 0, 0]
effects    u32 count u32 byteLength, then count records

Records start with a 4-byte head whose first byte is the tag, followed by fixed-size fields and at most two strings, each u32 byte length + UTF-8.

Imports Cairn.Frame, Cairn.Frame.Bytes

Round trip. Every frame whose values fit the wire's fields (fitsFrame, executable) and whose encoding is under 4 GiB decodes to itself.

Codes

What fits

The round trip holds for frames whose integers fit the wire's 32-bit fields and whose strings are shorter than 4 GiB. These are checks, not conventions: fitsFrame is executable.

Put.* writes the same bytes as Enc.* straight into a ByteArray. Section byte lengths are computed up front by Len.* (proved equal to the encoded lengths), so nothing is copied or patched afterwards.
