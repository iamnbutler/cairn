Cairn.Runtime.Step

lean/Cairn/Runtime/Step.lean

The interaction runtime: turns host events into the Actions an app's update sees.

step is two halves. route reads the event against the laid tree on screen and produces the new interaction state and a list of actions, each naming a control of that tree. step then hands the actions to app.update in order, re-runs view and layout, and repairs focus, hover and press against the new tree. The semantics are written out in docs/runtime.md.

Imports Cairn.App, Cairn.UI.Hit, Cairn.Layout.Core, Cairn.Runtime.World
