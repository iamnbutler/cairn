Cairn.Fuzz.Rng

lean/Cairn/Fuzz/Rng.lean

A seeded PRNG and generators

SplitMix64 (Steele, Lea and Flood, "Fast splittable pseudorandom number generators", 2014): a 64-bit state advanced by a constant, then mixed. Small, fast, good enough for test generation, and pure, so a seed replays a run exactly. Core only: no Plausible.

A module, so apps can write custom generators (Cairn.Fuzz.Custom) without linking Lean.
