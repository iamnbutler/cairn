Cairn.Text.Host

lean/Cairn/Text/Host.lean

Core Text metrics from the host, as a TextMetrics.

The host shapes each (font, string) once with Core Text and reports, in whole logical points, the font's ascent and descent and the caret offset at every Unicode scalar boundary; the renderer draws glyphs from the very same shaped line (docs/render.md). Lean receives the numbers as bytes through cairn_lean_text_metrics (lean/c/text_host.c), decodes them, and normalises them so TextMetrics.host satisfies TextMetrics.Valid by proof, whatever the host sends: host_valid below. What stays trusted is only that the numbers match what is painted (an assume, docs/trusted.md).

Linking: the extern symbols live in text_host.o, which Lake links into every executable and puts in libcairn_Cairn.a. The C function it calls, cairn_text_metrics, is defined weakly there (returning "no host"), so bench, audit and Lean tests link without the Swift host and get TextMetrics.mono numbers; the Swift host's strong definition wins when it is linked. hostLinked () says which one is in use. Never evaluate these at elaboration time (#eval, #guard): the interpreter has no native implementation to call.
