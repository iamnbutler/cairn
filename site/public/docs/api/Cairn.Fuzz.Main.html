Cairn.Fuzz.Main

lean/Cairn/Fuzz/Main.lean

lake exe fuzz

lake exe fuzz <App> [--seed S|random] [--iterations N] [--steps K] [--budget-ms M]
                    [--out DIR] [--shrink N] [-v]
lake exe fuzz --list

Runs sequences with seeds S, S+1, …, S+N−1 (the SEED and ITERATIONS environment variables set the defaults), stops each at its first failure, shrinks the first failure of each kind, prints it as a flow, and writes <DIR>/<App>.json (docs/fuzz.md). Exit code 1 when anything failed.

Imports Lean.Data.Json, Cairn.Fuzz.Shrink
