Cairn.Effect

lean/Cairn/Input.lean:134
Effect : Type

App → host (and runtime).

Constructors
setClipboard (s : String) : Effect
beep : Effect
focus (c : ControlRef) : Effect

Move keyboard focus to the control c. The runtime runs this one, not the host: after the step's actions it sets ui.focus := some c, and keeps it only if c is a focusable control of the new tree (docs/runtime.md). No blur is delivered for a field it takes focus from. The host decodes it and does nothing.

setTimer (name : String) (ms : Nat) : Effect

Start (or restart) the timer name, due ms milliseconds from now. The runtime keeps timers; the host only wakes it (docs/effects.md).

cancelTimer (name : String) : Effect

Forget the timer name; nothing if it isn't set.

request (id : Nat) (r : Request) : Effect

Ask the host to do r; it answers with Msg.reply id _, exactly once.

quit : Effect

End the app. The host terminates after running the frame's other effects.
