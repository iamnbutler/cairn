Cairn.Layout.Rigid

lean/Cairn/Layout/Rigid.lean

Rigid views: pressable at every size they fit, for every state

Layout/Check.lean proves a view pressable by evaluating its layout, which works for one concrete state, window and set of metrics. An app with a list of any length needs the same fact for all of them. This file gives a structural condition, FitsIn n w h, under which a view laid out in a w × h rect satisfies every per-node condition of Pressable and every control has a nonempty rect, for all text metrics.

The idea: in a rigid view every box and field is fixed or fill on both axes, never hug, so no rect depends on how wide a string is. Text appears only inside boxes that clip and hold nothing but text (Fits exempts those: the text may overflow, the clip contains it). Then each child's size is known from its parent's alone:

  • on the cross axis, fixed n gets n and fill gets the content box's length;
  • on the main axis, fixed n gets n, and fill gets a share of the leftover space, at least ⌊leftover / fills⌋ (fillShare_ge).

FitsIn asks, node by node, that the fixed children and gaps fit, that each child fits at the size it will get, and that controls have positive size. fitsIn_arrange proves the rest; hitTest_center_of_fitsIn turns it into "hit testing at the centre of every control returns that control". Positions never appear, so a list of k identical rows is handled by one argument about one row.

Cairn.Layout.FitsIn

lean/Cairn/Layout/Rigid.lean:91
FitsIn : Node → Int → Int → Prop

FitsIn n w h: laid out in a w × h rect, n and everything below it fit, and its controls have positive size. Three shapes:

  • wrapped text (a clipping column of lines, with no controls);
  • a field of positive size;
  • a box that clips and holds only text (a label: the text may overflow; the clip holds it);
  • a row or column whose children are all fixed or fill on both axes, whose fixed main-axis lengths and gaps fit its content box, whose fixed cross-axis lengths fit too, and whose every child fits at the size it will get. A fill child on the main axis must fit at every length from ⌊leftover / fills⌋ up. A box with a control has no controls below it.

The theorem

Example: a list of any length

A column of k buttons, each a clipped 44-point row holding a label. Every button is pressable at its centre, for every text metrics, whenever the window is wider than zero and at least 44 * k tall. The proof never looks at a particular k or a particular label.
