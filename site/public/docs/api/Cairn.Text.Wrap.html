Cairn.Text.Wrap

lean/Cairn/Text/Wrap.lean

Line breaking

Lean decides where wrapped text (Node.para) breaks; the host only measures. Everything here works on the text as a list of Unicode scalars and on its caret offsets o : Nat → Int (o i is the x offset before scalar i, from one Core Text shaping of the whole string, so a line [a, b) is o b - o a wide). The rules (docs/layout.md, "Wrapped text"):

  1. Words are maximal runs of scalars other than the break space U+0020 (isBreak). Lines break only between words, and the spaces at a break are dropped: a line runs from the start of its first word to the end of its last, with the spaces between its own words kept.
  2. Greedy fill (fill): a line takes words while the line, measured from its first scalar to the end of the next word, still fits; then the next word starts a new line.
  3. Over-wide words. A word that starts a line and is wider than the width is cut into pieces (chunk): each the longest run of its scalars, from where the last one ended, that fits, and never less than one scalar. Every piece but the last is a line of its own; the last starts a line that later words may join.
  4. At most maxLines, keeping the first (Keep.head) or the last (Keep.tail) lines.

Theorems (Cairn.Text.WrapProofs): every line fits the width or is a single scalar; the lines tile the text with only break spaces between and around them; the count is at most maxLines; tail keeps exactly the last lines and head the first.

Each function is structural recursion (fuel where the measure isn't), so #guard and decide evaluate it; the examples are in Cairn.Text.WrapProofs.
