Cairn.Fuzz.Collect

lean/Cairn/Fuzz/Collect.lean

fuzz_targets%: every fuzzable app, found at compile time

Elaborates to a List Cairn.Fuzz.Target, one per Machine declared in an app module (appModule: Examples, or an app package's own) of the imported environment. For each machine it collects, from the claim registry and the environment:

  • the App of the same state type declared in the machine's module (preferring <ns>.app);
  • the keyed moves of the machine's namespace;
  • the invariants stated against it, with their check when invariant generated one;
  • every claim the module declares;
  • <ns>.fuzz : Cairn.Fuzz.Custom S, if the app defines one.

So an app needs no fuzz code: importing it from Examples.lean is enough. Compile time only (imports Lean); the fuzz executable is the only thing that uses it.

Imports Lean, Cairn.Claims.Registry, Cairn.Fuzz.Target
