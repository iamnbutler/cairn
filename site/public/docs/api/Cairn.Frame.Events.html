Cairn.Frame.Events

lean/Cairn/Frame/Events.lean

Event byte format v2 (host → Lean, docs/frame.md): specification encoder Wire.Enc.events, decoder Wire.Dec.events, and the round trip decodeEvents_encodeEvents.

header  "CAEV" u16 version=2 u16 flags=0 u32 count                          12 bytes
events  count records, each [tag, a, b, 0] then fixed fields, then at most one string

A surface record (tag 21) is its head and a u32 place followed by one whole surface-local record (tags 0–17), so every record still stands alone.

Lean only decodes events at run time (the host encodes them), and a frame's events are a handful of records, so the decoder runs the list specification directly on the buffer's bytes.
