Cairn.Runtime.WorldProofs

lean/Cairn/Runtime/WorldProofs.lean

What the runtime guarantees about the outside world (docs/effects.md, "Semantics").

  • The clock never goes back (step_clock).
  • A timer reaches receive only while it is set: a cancelled timer never fires, and a timer fires once per setting (steps_book, read with Book.run).
  • A reply reaches receive only for a pending request, with the id it was sent under, in the shape that answers its kind, and once (steps_book, step_reply, step_reply_ignored).
  • Subscription diffs start exactly the wanted subscriptions that are not running, stop exactly the running ones no longer wanted, and the active set becomes what the app wants (diffSubs_stop, diffSubs_start, diffSubs_active).

The timer and reply statements are about a recording wrapper, logged app, whose state carries the list of everything delivered to receive and update, with the effects each returned. Book.run is the specification such a log must meet: it replays the log against a book of armed timers and pending requests and fails at the first delivery the book does not allow.
