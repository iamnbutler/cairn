Theorems about Cairn.Text.Field

  1. In bounds. Field.wf_empty, Field.wf_ofString, Field.wf_apply, Field.wf_applyAll, Field.wf_reachable, Field.view_wf: caret, anchor, marked range and every undo and redo entry stay within 0 … length, from any well-formed field, for every op.
  2. Round trip. Field.insert_deleteBackward, Field.insert_deleteBackward': typing s at a collapsed caret, then deleting backward s.length times, restores the text and selection.
  3. Undo. Field.undo_apply (one edit, outside a typing run or composition), Field.undo_typing_run (a run of coalesced typing), Field.undo_composition (a whole IME composition), Field.redo_undo.
  4. Selection replace. Field.insert_replaces_selection, Field.insert_replaces_selection', Field.insert_replace.
  5. Copy is pure. Field.apply_copy, Field.selected_spec.
  6. Movement never edits. Field.apply_movement_text.
  7. Single line. Field.singleLine_apply, Field.view_no_newline (and WF.single).

undo_typing_run (f : Field) (op : TextOp) (ops : List TextOp)
  (hop : op.isTyping = true) (hops : ∀ (o : TextOp), o ∈ ops → o.isTyping = true)
  (htyping : f.typing = false) (hm : f.marked = none) (hc : f.anchor = f.caret)

Coalesced typing. A run of typing (inserts, and single-scalar deletes) at a collapsed caret, each step changing the text, is one undo step: undo after the whole run restores the text and selection from before its first keystroke.

Cairn.Text.Field.undo_composition

provedlean/Cairn/Text/Proofs.lean:532
undo_composition (f : Field) (hm : f.marked = none) (s : String)
  (i n : Nat) (more : List (String × Nat × Nat)) (hs : 0 < s.length)
  (hmore : ∀ (x : String × Nat × Nat), x ∈ more → 0 < x.fst.length) :
  have ops :=
    TextOp.setMarked s i n ::
        List.map (fun x => TextOp.setMarked x.fst x.snd.fst x.snd.snd) more ++
      [TextOp.unmark];
  have g := (f.applyAll ops).undo.fst;
  g.text = f.text ∧ g.caret = f.caret ∧ g.anchor = f.anchor

Composition is one undo step. From a field with no composition, a composition (one or more non-empty setMarked) and its commit (unmark) undo back to the field before it.
