Cairn.Surface

lean/Cairn/Surface.lean

What an app shows besides a window (docs/surfaces.md): a menu bar status item with its native menu, and a non-activating, click-through overlay panel, both as data. Cairn.App collects an app's surfaces; the runtime keeps what each one shows (Cairn.Runtime.Shown) and the frame carries it (docs/frame.md, surface records).

The menu is a description, not a laid tree: the host builds a real NSMenu from it, and every actionable item is a Control naming a move, so presence, enablement and checkmarks are facts about this value (refs, enabledOf, checkedOf) with no layout in between.

MenuItem is a nested inductive, so every function over it is a structural pair (f on one item, fs on a list), per AGENTS.md.

Imports Cairn.UI.Node, Cairn.Input
