Cairn.UI.Hit

lean/Cairn/UI/Hit.lean

Hit testing over a laid-out tree.

Paint order is pre-order: a node paints before its children, and children paint in list order, so later entries are on top. Every node that paints (a box with a background, border or control, every text run and every field) leaves a hit entry: its visible rect (rect.inter clip) and its owner, the nearest control at or above it. A point hits the topmost entry that contains it, and the hit goes to that entry's owner. So a label inside a button routes to the button, and an opaque panel painted over a button blocks it.
