Cairn.Layout.Para

lean/Cairn/Layout/Para.lean

Wrapped text in layout

measure turns Node.para ts wr s into a clipping column (paraStyle wr) of one Sized.text per line (paraLines). The lines come from Cairn.Text.Wrap.lines on the offsets of one measurement of s, at wrapWidth wr aw. Because a para is a box of text once measured, arrange, Laid, the frame and hit testing are unchanged, and every layout theorem (Cairn.Layout.facts, Pressable, fitsIn_arrange) covers views with wrapped text in them.

What is proved here, for every metrics m and offered width aw:

  • para_lines_fit: every line's measured width is at most the wrap width (when that is non-negative), or the line is a single scalar;
  • para_lines_tile: the lines, with break spaces only put back between and around them, are the text (without maxLines); para_lines_tail / para_lines_head: with maxLines, they are exactly the last / first lines of that;
  • para_count: at most maxLines lines;
  • para_height: a hug para is lines × line height tall, each line one line height; layout_para_height: so is a root para's rect.

measure_para (m : TextMetrics) (aw : Int) (ts : TextStyle) (wr : Wrap)
  (s : String) :
  measure m aw (Node.para ts wr s) =
    Sized.box (paraStyle wr) none
      {
        w :=
          resolve wr.width
            (contentSize Axis.column wr.lineSpacing
                (List.map Sized.size (paraLines m ts wr aw s))).w,
        h :=
          resolve wr.height
            (contentSize Axis.column wr.lineSpacing
                (List.map Sized.size (paraLines m ts wr aw s))).h }
      (paraLines m ts wr aw s)

paraLines_eq (m : TextMetrics) (ts : TextStyle) (wr : Wrap) (aw : Int)
  (s : String) :
  paraLines m ts wr aw s =
    List.map
      (fun p =>
        Sized.text ts (String.ofList (Text.Wrap.slice s.toList p))
          { w := max 0 (Text.Wrap.width (paraOffsets m ts s) p),
            h := max 0 (m.lineHeight ts.font) })
      (Text.Wrap.lines (paraOffsets m ts s) (wrapWidth wr aw) wr s.toList)

para_lines_tail (m : TextMetrics) (ts : TextStyle) (wr : Wrap) (aw : Int)
  (s : String) (n : Nat) (hm : wr.maxLines = some n) (hk : wr.keep = Keep.tail) :
  have all :=
    List.map (Text.Wrap.slice s.toList)
      (Text.Wrap.allLines (paraOffsets m ts s) (wrapWidth wr aw) s.toList);
  ∃ pre,
    pre ++ paraStrings m ts wr aw s = all ∧
      (paraStrings m ts wr aw s).length = min n all.length

Keep tail. With maxLines = some n and keep = .tail, the lines shown are exactly the last min n k of the k lines the text breaks into.
