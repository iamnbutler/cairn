Cairn.Layout.Core

lean/Cairn/Layout/Core.lean

Layout

layout m window node turns a Node into a Laid: every rect, clip, baseline, caret and selection resolved in integer logical points. It is total and pure, and works in two passes:

  1. Measure (measure, bottom-up): each node's preferred ("hug") size, stored in a Sized tree so that no subtree is measured twice. It is passed the width the parent offers, which only wrapped text (Node.para) uses: a para measures into a clipping column of its lines, one text each (paraLines), so arrange never sees a para.
  2. Arrange (arrange, top-down): each node is given a rect by its parent and places its children inside its content box.

The semantics are specified in docs/layout.md; the theorems are in Cairn.Layout.Proofs. Every definition here is plain structural recursion over lists so that the proofs can follow the code.

Imports Cairn.UI.Node, Cairn.Text.Wrap

Cairn.Layout.Sized

Sized : Type

A node with its preferred size resolved. This is the measure pass's output and the arrange pass's input. size is the size the node asks for: fixed n gives n, hug and fill give the intrinsic size of the content plus padding, floored at zero.
