Cairn.Fuzz.Metrics

lean/Cairn/Fuzz/Metrics.lean

Random text metrics, valid by construction

Layout and text theorems quantify over every TextMetrics that is Valid, so the fuzzer shouldn't test with the mono stand-in only. random seed gives each font its own widths: each scalar's width is a hash of the seed, the font and the scalar, between 30% and 90% of the font size (wider for CJK and emoji), and 0 for combining marks and zero-width joiners; offsets are their prefix sums. Ascent and descent are random fractions of the size. random_valid proves every such metrics Valid.

Imports Cairn.Fuzz.Rng, Cairn.Font, Cairn.Layout.Proofs
