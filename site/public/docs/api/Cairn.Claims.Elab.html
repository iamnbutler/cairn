Cairn.Claims.Elab

lean/Cairn/Claims/Elab.lean

The claim commands: move, flow, invariant, assume, place and retire, and the moves% and claims% terms. See docs/claims.md for the syntax and what each check guarantees.

Each command elaborates to ordinary declarations (definitions for the formal statement, theorems for the evidence, a ClaimInfo and a value of the claim's structure) and records an Entry in the registry. Every check happens here, at compile time:

  • an id is issued once in the whole imported environment;
  • every claim has a title and says what it does (does); a move also says what follows (sees);
  • in ^P names a place that exists;
  • a move has a handler per trigger, and each handler has apply (or emit), post and a sound proof, so a move without a proof does not compile;
  • a flow's witness names moves that exist, and its live and reaches proofs check;
  • a retired id says why;
  • no move is declared after moves% collected its namespace, and no claim after claims%.

Cairn.Claims.instInhabitedItem

lean/Cairn/Claims/Elab.lean:88
instInhabitedItem : Inhabited Item

Syntax

The command keywords are not reserved: move, place and the rest stay usable as identifiers (ClaimKind.place, a field called move). A plain &"move" is not found by the command parser when it starts a command, so each keyword is a non-reserved symbol that also indexes under identifiers.
