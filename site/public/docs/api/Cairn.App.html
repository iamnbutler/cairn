Cairn.App

lean/Cairn/App.lean

An app is its state, its surfaces, and its moves. The runtime (Cairn.Runtime) owns interaction state (hover, press, focus, window size), turns events into actions by hit testing the laid-out frame or checking the menu, and calls update.

Fields

What the app shows: at most one window (a later window is ignored), panels and status items. An app with no window is an accessory app (no Dock icon, no main menu).

update : S × List Effect

A person's moves: every action names a control on screen.

receive : S × List Effect

The outside world: the clock, timers, replies and subscription events (docs/effects.md). Ignored by default.

subscriptions : List Sub

The outside inputs the app wants in this state. The runtime diffs them after every delivery and starts and stops subscriptions to match.

initEffects : List Effect

Effects to run once, when the first clock arrives (so timers start from a real time).

Every claim the app makes, from the claim commands.

The control that has keyboard focus at launch, if it is focusable there.

Cairn.Surface

lean/Cairn/App.lean:31
Surface (S : Type) : Type

One thing an app shows (docs/surfaces.md). An app declares a fixed list of them; whether each is shown, and what it shows, is a function of the state. place is the surface's place claim: its durable identity on the wire, in the map and in the debug socket.

Constructors
window {S : Type} (place : ClaimId) (title : String) (view : S → UI → Node) :
  Surface S

M1's window: Metal content laid out at the window's size, with input.

panel {S : Type} (place : ClaimId)
  (view : TextMetrics → S → Option PanelView) : Surface S

A non-activating, click-through overlay panel; none hides it. It takes no input, so its view doesn't read UI. The view is given the text metrics the panel is laid out with, so it can measure content (Cairn.Layout.measure), for instance to animate between two heights.

statusItem {S : Type} (place : ClaimId) (view : S → Option StatusItem) :
  Surface S

A menu bar status item and its native menu; none removes it from the menu bar.

firstWindow_comap {S T : Type} (f : T → S) (xs : List (Surface S)) :
  firstWindow (List.map (Surface.comap f) xs) =
    Option.map
      (fun x =>
        match x with
        | (p, t, v) => (p, t, fun s ui => v (f s) ui))
      (firstWindow xs)
