Cairn.Claims.Machine

lean/Cairn/Claims/Machine.lean

A machine is an initial state and the moves that act on it. Its update is derived from the moves by dispatch, so it inherits every guarantee in Cairn.Claims.Move. Flows and invariants are stated against a machine.

A machine may also hear the outside world (docs/effects.md): receive takes the clock, timers, replies and subscription events. An invariant must be kept by receive as well as by every move, so it holds over any interleaving of a person's actions and the host's messages (Invariant.reachableAll), and through the runtime (Cairn.Claims.steps_reachableAll).

Pure, and linked into the host, like Cairn.Claims.Move.

Imports Cairn.Claims.Move, Cairn.App
