Cairn.Layout.Bridge

lean/Cairn/Layout/Bridge.lean

From layout facts to the runtime's LayoutFacts

The runtime's pressable theorems (Cairn.Runtime.hitTest_center, click_center_presses) take Cairn.Runtime.LayoutFacts laid t: the control's visible rect is nonempty and a pointer at its centre reaches it. This file proves that every control of layout m w n satisfies it, given four conditions an app can check about its view (Pressable):

  1. It fits. In every container, padding is non-negative, each child is no larger than the content box, and in a row or column the children plus gaps fit along the main axis (Fits). This is where the minimum window size comes in. A box that clips and holds only text is exempt: its text may overflow (a long title, a label under unusual metrics), but the clip keeps everything it paints inside its rect, and text has no controls.
  2. The root is inside the window.
  3. Stacks keep controls on top. In a stack, only the last child may contain controls (StackTop): earlier children are backgrounds that later ones paint over.
  4. Controls are leaves for hit testing. A box with a control has no controls below it (ControlLeaf), so a label inside a button routes to the button.

Then every control whose rect is nonempty is pressable at its centre (layoutFacts_of_pressable), and indeed at every point of its visible rect (reaches_of_pressable).

Cairn.Layout.layoutFacts_of_pressable

layoutFacts_of_pressable {m : TextMetrics} {w : Size} {n : Node}
  (hp : Pressable w (layout m w n)) {t : Runtime.Target}
  (ht : t ∈ Runtime.targets (layout m w n)) (hne : t.node.rect.nonempty) :
  Runtime.LayoutFacts (layout m w n) t

The bridge. If the view is Pressable, every control whose rect is nonempty satisfies the runtime's LayoutFacts: its visible rect is its whole rect, and a pointer at the centre reaches it. So Cairn.Runtime.hitTest_center and click_center_presses apply.
