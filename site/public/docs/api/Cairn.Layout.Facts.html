What layout guarantees

The vocabulary for the layout theorems: controls of a tree, a predicate holding at every node (Laid.Everywhere), the local facts layout establishes at each node, and Facts, the package the runtime's pressability proof consumes. The theorems are in Cairn.Layout.Proofs.

Facts (m : TextMetrics) (window : Size) (n : Node) (l : Laid) : Prop

Everything layout m window n guarantees about its result l. The runtime's pressability theorem takes these as hypotheses; Cairn.Layout.facts proves them for every view, window and valid metrics.

Cairn.Layout.FillExact

FillExact : Laid → Prop

Fill exactness: in a row or column, if some child fills the main axis and the other children, gaps and padding fit, then children, gaps and padding span the parent exactly. Each child is described by its main-axis sizing and length.

Cairn.Layout.ChildrenInside

lean/Cairn/Layout/Facts.lean:112
ChildrenInside : Laid → Prop

Children that fit stay inside: if every child's rect is no larger than the content box and, in a row or column, the children plus gaps fit along the main axis, then every child's rect is inside the content box. Together with SiblingsDisjoint, this means nothing in one child's subtree can cover another child, as long as the view fits.

Cairn.Layout.CaretPlaced

lean/Cairn/Layout/Facts.lean:126
CaretPlaced (m : TextMetrics) : Laid → Prop

Field geometry: the caret sits at the text origin plus the caret's offset, within the text's extent, is one point wide and a line high, and is inside the content box horizontally whenever the content box is at least one point wide (the text scrolls to keep it there). The selection is empty when collapsed and otherwise runs between the offsets of its ends.
