Cairn.Frame.Bytes

lean/Cairn/Frame/Bytes.lean

The byte layer of the boundary format (docs/frame.md): little-endian primitives, three ways.

  • Enc.* encode to List UInt8. They are the specification: short, and what the round-trip theorems talk about.
  • Dec is a decoder over List UInt8 (consume a prefix, return the value and the rest). Each primitive has a round-trip lemma of the form d (Enc.x v ++ rest) = some (v, rest), which is what makes the whole-frame theorems compose.
  • Put.* append to a ByteArray. They are what runs; Put.x_data says each one appends exactly Enc.x to the buffer's bytes.

Integers that cross the boundary are 32-bit: Int as two's complement (i32), Nat as unsigned (u32). The round trip needs the value to fit, stated with FitsI32 and FitsU32.
