Cairn.Rect.inter

lean/Cairn/Geometry.lean:60
inter (a b : Rect) : Rect

Intersection, used for clipping. Width and height floor at zero. When the rects don't overlap, the empty result is placed inside a (its origin is clamped to a's far edge), so a.inter b is inside a whenever a has non-negative size.
