Cairn.Fuzz.Trusted.Claims

lean/Cairn/Fuzz/Trusted/Claims.lean

The trusted base's assumptions (docs/trusted.md), each naming the check of the trusted-base fuzzer that gathers its evidence (make fuzz-trusted, build/fuzz/trusted.json, docs/fuzz.md "Trusted base"). Evidence, not proof: these stay assumptions.

Ids 901–999 and 1000 on are for framework-level assumptions; apps' own assumptions use their apps' ranges. Not imported by Cairn (the host links that); the ledger reads this module as a root.

Imports Cairn.Claims.Core, Cairn.Claims.Elab
