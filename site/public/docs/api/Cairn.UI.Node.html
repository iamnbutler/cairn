Cairn.UI.Node

lean/Cairn/UI/Node.lean

What view returns (Node) and what layout produces (Laid).

A Node says what is on screen and how it wants to be sized; layout turns it into a Laid with every rect and clip resolved. A node that performs a move carries a Control naming the claim, which is how presence, pressability and the accessibility mirror find it.

Imports Cairn.Geometry, Cairn.Claim, Cairn.Font
